# ottomiles.app

Coming-soon landing page for **OttoMiles** — mileage & earnings tracking for
rideshare and delivery drivers. Static site served by GitHub Pages at
[ottomiles.app](https://ottomiles.app).

- `index.html` — the page (hero teaser video, click-to-play, coming-soon)
- `privacy/index.html`, `terms/index.html` — the Privacy Policy and Terms of Service, linked from the app (paywall, About) and App Store Connect at `https://ottomiles.app/privacy/` and `https://ottomiles.app/terms/`. Self-contained pages: no external requests. Bump the "Last updated" date whenever the copy changes
- `ottomiles-teaser.mp4` / `poster.jpg` — hero video + its final-frame poster
- `favicon.svg`, `apple-touch-icon.png` — icons (shared with the app)
- `CNAME` — custom domain binding for GitHub Pages
